# CLAUDE.md — Grant Architect Bot

## Кто здесь работает

**Lia** — строит гибридный AI-инструмент для превращения идей в деньги.
Основной бизнес: **Lia Strategy and AI Automation**.

---

## Главная система (Уровень 1)

```
Lia Strategy and AI Automation
= Idea-to-Money OS (Meaning Tunnel OS)
```

Одна механика для всех направлений:

```
Идея
  → Смысловой туннель (контент, reels, посты)
  → Кодовое слово / вход
  → Бот / DM
  → Прогрев
  → Созвон / оффер
  → Продажа
  → Деньги
```

Эта механика **не зависит от ниши**. Она применяется к Taro, к грантам, к недвижимости и к любому бизнесу клиента.

---

## Этот репозиторий: Grant Architect Bot

**Что это:** Telegram-бот на Python (aiohttp + python-telegram-bot)
**Текущая функция:** Загружает файлы уроков курса Grant Architect в GitHub

**Где живёт в общей системе:**
```
Уровень 4 (Технический слой)
→ Telegram-боты
→ grant-architect-bot ← ВЫ ЗДЕСЬ
```

**Что должен делать бот в идеале:**
1. Принять человека после кодового слова или рекламы
2. Задать 3 вопроса о проекте
3. Показать 2–3 подходящих гранта
4. Предложить следующий шаг: заявка, созвон, оплата

**Текущий статус:** Бот работает как инструмент курса. Воронка перед ботом ещё не настроена.
